### Disciplina ministrada pelo Professor André Olímpio.

Este repositório é dedicado à disciplina de **Programação Web** do 4º semestre do curso de Análise e Desenvolvimento de Sistemas (ADS) da **FATEC**.

Aqui você encontrará as atividades e projetos desenvolvidos ao longo da disciplina.

---
### Projetos incluídos:
- **CrudMundo**: (Submódulo) Sistema de Gerenciamento Geográfico para continentes, países, estados e cidades, com operações CRUD, integração de APIs externas e autenticação.
- **Cinema**: Aplicação TypeScript para gerenciamento de catálogo de filmes.
- **Portfolio**: Portfólio pessoal desenvolvido em HTML/CSS conforme requisitos avaliativos.
- **To_Do_List**: Aplicação para gerenciamento de tarefas com níveis de prioridade e datas limite.
