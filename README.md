## Programação Web - 4ADS - Fatec Jessen Vidal
### Disciplina ministrada pelo Professor André Olímpio de Lima.

Este repositório é dedicado à disciplina de **Programação Web** do 4º semestre do curso de Análise e Desenvolvimento de Sistemas (ADS) da **FATEC**.

Projetos desenvolvidos ao longo da disciplina:

- **[CrudMundo](./CrudMundo/README.md)**: (Submódulo) Sistema de Gerenciamento Geográfico para continentes, países, estados e cidades, com operações CRUD, integração de APIs externas e autenticação.
- **[Cinema](./Cinema/README.md)**: Aplicação TypeScript para gerenciamento de catálogo de filmes.
- **[Portfolio](./Portfolio/README.MD)**: Portfólio pessoal desenvolvido em HTML/CSS conforme requisitos avaliativos.
- **[To_Do_List](./To_Do_List/)**: Aplicação para gerenciamento de tarefas com níveis de prioridade e datas limite.
